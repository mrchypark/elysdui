# UI attribution

elysdui UI uses Go `html/template`, htmx, Tailwind CSS and adapted shadcn-htmx components. Shared theme, font and asset files are in `assets`. Shared UI templates are in `templates`.


The application also uses the locally vendored [htmx 4.0.0 distribution](https://github.com/bigskysoftware/htmx/releases/tag/v4.0.0) at `/assets/htmx.min.js`, under the Zero-Clause BSD license. The license is included in `assets/htmx.LICENSE.txt`.

The visual reference is [Ely](https://elygpui.com/). The catalogue and shared HTML implementations in the root package derive from [Ely GPUI Component](https://git.zacharyzhang.com/ZacharyZhang-NY/Ely-GPUI-Components), revision `49ed1f84056fa13347d68801b479a4a5a8e03b53`, under MIT. The license is included in `assets/ely/LICENSE.txt`. elysdui renders native HTML/SVG adaptations; it does not run the Ely/GPUI WASM runtime.

The SVG icons in `assets/ely/icons` are bundled from that Ely source revision. They carry the Lucide ISC notice and the Feather MIT notice in `assets/ely/icons/LICENSE`. Preserve that complete license file when exporting or copying the icons. The deployed reference gallery can use a different icon set from this source revision.

[shadcn-htmx](https://github.com/productdevbook/shadcn-htmx), revision `7c96261`, is an independent shadcn-style Go/htmx port under MIT. Adapted sources are in `templates/shadcn-*.html`; the license is in `assets/shadcn-htmx.LICENSE.txt`. Progress uses native `<progress>` for strict CSP. Badge uses a fixed `<span>` for `html/template` compatibility; keyboard initialization is external JavaScript. These sources do not introduce a React runtime.

Locally hosted Geist and Geist Mono are from [vercel/geist-font](https://github.com/vercel/geist-font), under SIL Open Font License 1.1. The license is included at `assets/geist-font.LICENSE.txt`. Pretendard is from [orioncactus/pretendard](https://github.com/orioncactus/pretendard), under SIL Open Font License 1.1, with its license at `assets/pretendard-font.LICENSE.txt`.

The shared map uses locally vendored Natural Earth 110m country boundaries (177 features), a public-domain dataset. Source and retrieval details are stored in `assets/ely/world-land.json` under `provenance`. Maps do not request third-party tiles or geolocation by default. Optional trusted host-registered raster providers are described in [map tiles](https://github.com/mrchypark/elysdui/blob/main/docs/gohtmx/map-tiles.md). Bundled Natural Earth PNG tiles (zooms 0–3) and the shared-edge layout adaptation come from Ely GPUI revision `da3fdcaf39f2fa85ce1dd9cad07c3c81cf1dd721`; their MIT notice and exact provenance are in `assets/ely/tiles/LICENSE.txt` and `assets/ely/tiles/provenance.json`. The no-key consumer example requests only local assets.

Goldmark v1.8.6 (MIT) renders GFM Markdown with raw HTML and unsafe URL schemes disabled. Source: https://github.com/yuin/goldmark. License: `assets/ely/licenses/goldmark-LICENSE.txt`.

boombuler/barcode v1.1.0 (MIT) encodes caller values as QR, Code128 and EAN-13. Source: https://github.com/boombuler/barcode. License: `assets/ely/licenses/barcode-LICENSE.txt`.

Lottie-web v5.13.0 light SVG distribution (MIT), from the npm registry with SHA-512 integrity verification, is vendored at `assets/lottie-light.min.js`. Source: https://github.com/airbnb/lottie-web. License: `assets/ely/licenses/lottie-web-LICENSE.md`. The light build omits expression execution.
Tailwind CSS and @tailwindcss/cli v4.1.18 (MIT) build the checked-in stylesheet. Source: https://github.com/tailwindlabs/tailwindcss. License: `assets/tailwindcss.LICENSE.txt`.

KaTeX v0.19.0 (MIT), from the npm registry, is vendored at `assets/ely/katex/katex.js` with its license at `assets/ely/katex/LICENSE`. Source: https://github.com/KaTeX/KaTeX. Formula components load it only when needed and use MathML output with trusted HTML and external-resource commands disabled. Native MathML displays the result without KaTeX's HTML styles or font assets.

`sample.svg`, `sample-before.svg`, `sample.gif`, and the gallery-only `audit-tone.wav` and `audit-video.mp4` are original geometric/test-pattern/tone fixtures generated by `scripts/fixtures.py`, under this project's MIT license. They contain no photos, people, recordings, or app data. Copied Ely photo/GIF/page assets and application logos/favicons are excluded.

`assets/ely/native-tone.wav` and `assets/ely/native-neutral.webm` are original local tone and neutral-frame fixtures under this project's MIT license. They contain no recordings or application data. `scripts/fixtures.py` also regenerates playable examples for these paths.

`assets/ely/native-architecture.svg` is an original geometric architectural illustration under this project's MIT license. It contains no photograph or application data. `scripts/fixtures.py` regenerates it.

### Emoji catalogue

The gallery uses the Unicode 17 emoji catalogue from `emojis` 0.9.0, the version used by Ely GPUI. Names, groups, shortcodes, and default variants are retained. No Rust runtime dependency is added. License copies: `assets/ely/LICENSE-MIT-emojis.txt` and `assets/ely/LICENSE-UNICODE-emojis.txt`.

Regional gallery choices are derived from the same pinned upstream dependencies: `isolang` 2.4.0 (184 ISO 639-1 languages), `isocountry` 0.3.2 (249 countries), and `iso_currency` 0.7.1 (154 active currencies, excluding funds and special codes). Their license copies are in `assets/ely/LICENSE-<package-version>.txt`. No Rust runtime dependencies are added.

The default Inter and JetBrains Mono fonts are copied from the same Ely revision above. Their SIL Open Font License notices are included at `assets/ely/fonts/Inter-LICENSE.txt` and `assets/ely/fonts/JetBrainsMono-LICENSE.txt`. The fonts are served locally.

## Project identity

elysdui is an independent project inspired by Ely GPUI, not affiliated with or endorsed by it. The original `assets/elysdui-mark.svg` shows overlapping flat screen frames with a shared definition. It is not Ely's isometric E logo and does not reuse or trace its geometry. The shared neutral colors and Inter / JetBrains Mono typography retain the credited Ely visual foundation. Code licensing is not treated as permission to claim upstream identity or endorsement.

Use this one asset for the hub, gallery, playground and favicon. Its monochrome silhouette follows the active theme in page headers; the standalone SVG follows the system theme. Do not introduce renderer-specific project logos or separate decorative palettes. Platform-specific controls may retain their native appearance.
