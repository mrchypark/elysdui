# CommandPalette reentry guard causal control

This is supplemental repair evidence. The original nine-case baseline and the
six initial reentry reports remain historical records; the initial reentry
reports fail their incorrect document-bubble timing prerequisite. The corrected
pre-swap queued checkpoint establishes the ordering independently in fresh CI.

The reentry workflow runs each actual Go-qualified, Go-chapter and compiled SDUI
fixture twice. `control` serves the committed guarded runtime. `guard-removed`
removes one exact 1,321-byte post-focus guard block from the served runtime only.
The committed source, template, fixtures and observer remain identical between
modes. A source-owned module pins the complete runtime source SHA256, complete
reversed runtime SHA256 and removed block SHA256. The loader rejects source drift,
missing or duplicate anchors before browser startup. Every other asset and all
rendered fixture bytes retain source/served equality.

The native gesture and passive raw observer are unchanged. They use ordinary
opening, trusted `op`, trusted Tab to Open and trusted ArrowDown. The native query
focus callback swaps the old Option row using the bundled public `htmx.swap`
API and a browser-fetched, independently rendered HTTP fragment. The queued
checkpoint was scheduled before invoking the swap. Required native identity,
mutation batches, cleanup, fragment bytes and lifecycle ordering are replayed
from current source, including all 33 prerequisites.

Both original desired safety assertions are unchanged:

- the old handler cannot replace the focus-return active pair after disposal;
- every captured active-reference write resolves to a live selected option.

This does not establish that every intermediate state while readiness is null
has a selected active reference. The guard stops the disposed continuation;
normal remount subsequently restores the live selection and reference.

A causal report is accepted only when every prerequisite passes and both
source-owned designated safety assertions fail. A surviving reversal is rejected.
The raw browser exit remains nonzero, so causal matrix jobs deliberately remain
red. There is no pass inversion or expected-red exemption. Ordinary control
regressions also remain red. Infrastructure, inventory and source errors cannot
masquerade as causal failures.

Run the offline source/schema controls with:

```sh
node scripts/palette-query-reentry-evidence-test.mjs
node scripts/palette-query-reentry-guard-evidence-test.mjs
node scripts/palette-query-reentry-replay-test.mjs
```

The replay regression compiles actual current-source fixtures, checks that all
trusted metadata survives JSON serialization exactly, and runs positive control
and reversal CLI replays with explicitly synthetic raw observations. Both reject
a wrong independently supplied expected mode. It starts no browser or server.

Native execution is CI-only. Each artifact includes the mode-qualified raw report,
pre-browser invocation, exit record and actual fixture HTML. Replaying an artifact
requires the expected revision, tree, token and mode from independent run records:

```sh
node scripts/palette-query-reentry-replay.mjs REPORT INVOCATION EXIT REVISION TREE TOKEN MODE
```

Replay rebuilds current Go/SDUI fixtures, hashes current source and assets, applies
only the fixed served reversal and compares the independent input inventory before
recomputing every raw assertion. Synthetic schema and corruption controls are
validator checks, never browser evidence.
