# Foundation component API

Foundation serves the `primitives`, `typography`, and `layout` chapters through `ui.Component`. Use a primary story name or a catalogue alias with an instance ID. The shared wrapper supplies `ID`, `Chapter`, `Kind`, `Variant`, and `ComponentName`; callers must not rely on changing those values.

Stories consume only the properties that define their own content. Use `Label` for every ARIA-bearing story; `Title` remains a compatibility fallback where a label is absent. `Items` is a `[]string`; `Label`, `Name`, `Required`, and `Disabled` configure native controls; and `Before`, `After`, `Alt`, `Caption`, `Citation`, `DateTime`, `Href`, `Src`, and `Key` supply matching semantic content. `Canvas` accepts `Points` as comma- or space-separated x/y pairs. `Latex` uses `mountMathML` from `/assets/ely-math.js`, which lazily loads bundled KaTeX 0.19.0 and preserves `Value` for copy and accessibility. It imports KaTeX MathML only, with `output: 'mathml'`, `trust: false`, `throwOnError: true`, `maxExpand: 1000`, `maxSize: 10`, and a fresh macro map for every instance. Errors leave escaped source text and set `data-foundation-math-fallback="true"`; all completed attempts set `data-foundation-math-ready="true"`. The same helper accepts `data-ely-math` and reports `data-ely-math-ready` and `data-ely-math-fallback` for communication MathBlock. It returns a cleanup that cancels a pending mount. `AnimatedNumber` accepts numeric `Value`, optional numeric `From`, and `Duration` milliseconds. Gallery specimens may also use `AnimatedNumbers` with `{Label, Value, Values, Decimals, Mode, Duration}`. `Typewriter` accepts `Value` and `Duration` milliseconds; gallery line specimens may use `TypewriterLines` and `NextLabel`. Motion ends immediately when `Disabled` is true or the user prefers reduced motion. `CurrencyText` accepts ISO `Currency`; `PluralText` accepts `Unit`. Numeric typography uses grouped English figures, fixed precision, a typographic minus, and tabular figures. `FileSizeText` uses decimal units by default; set `Binary: true` for KiB-based units. `RelativeTime` and `DateTimeText` read ISO-8601 `DateTime`. Empty values remain empty; no specimen content is used as a fallback.

`Title` pairs `Value` with `Text`. `Paragraph` accepts `Value` and is bounded to its readable source measure. `Blockquote` accepts `Value` and optional `Citation`. `Highlight` accepts existing `Label`/`Value` markup or `Text` with case-insensitive `Query`; matching is built from escaped text nodes at mount. `Truncate`, `LineClamp`, `MiddleEllipsis`, and `EllipsisTooltip` accept optional numeric `Width`; `LineClamp` also accepts `Lines`. `Truncate` may use `Before` as its fixed leading label. `Link` accepts optional `Before` and `After`; `ExternalLink` keeps native safe-new-tab semantics. `Label` accepts `Labels` for an inline collection or its existing native-control fields. `Caption` accepts `Value`; `Overline` accepts `Value` and optional `Version`; `Code` accepts optional `Before` and `After` around `Value`. `Kbd` accepts `Keycaps`, a list of `{Label, Keys}` maps, and `KbdCombo` accepts `KeyCombos`, a list of `{Label, Groups}` maps where each group supplies `Keys`; both retain their single-key fallback properties. `Divider` accepts `Orientation` (`horizontal` or `vertical`), `Label`, `Before`, and `After`; `Dividers` may provide several such maps. `Heading` accepts `Level` 1–6, with invalid values rendered as `h1`; `Headings` may provide several `{Level, Value}` maps. `Stack` accepts `Direction`, `Align`, and `Variant` (`HStack` or `VStack`); `Stacks` may provide labelled stack maps. `GridItems` accepts `{Label, Span}` maps. `SimpleGrid` uses `Items` as equal 140px-minimum tiles. `MasonryItems` accepts `{Label, Height}` maps and packs each bounded-height tile into the shortest of three columns. `AspectRatio` accepts positive numeric `Ratio`; `Aspects` may provide several `{Ratio, Value}` maps. `MiddleEllipsis` accepts optional numeric `MaxChars`; without it, the full value remains visible until the available inline width requires middle truncation and recomputes when that width changes.

`Icon` also accepts `IconSamples` (`Name`, `Label`, optional `Size` and `Tone`) for labelled size and tone collections; `SvgSamples` accepts `Name`, `Label`, and optional `Size`, `Tone`, and `Rotate` for labelled asset variants. `Icon` accepts `Icons`, a `[]string` of supported named icons, and retains legacy `Value`: a known name uses its icon while another escaped glyph remains text. `Svg` accepts `Icons` or a same-origin `/assets/*.svg` `Src` or `Path`. Unknown named icons render the safe fallback icon. `IconSet` uses `Items` as named icons. No icon property accepts SVG or HTML markup. The bundled names are available through `ui.FoundationIconNames()`; assets are served from `/assets/ely/icons/` under the included Lucide ISC and Feather MIT notices at `/assets/ely/icons/LICENSE`. `Box` accepts `Boxes` (`[]map` with `Tone`) and `Code`, and falls back to escaped `Value` then `Text` when no boxes are supplied. `Text` accepts `Runs` (`[]map` with `Value` and optional `Accent`) and `Code`, and has the same escaped `Value` then `Text` fallback. `Portal` accepts `Label`, `Text`, `Value`, and `Disabled`. `Overlay` accepts `Label`, `Title`, `Text`, `CloseLabel`, and `Disabled`. `Show` accepts `Checked`, `Label`, optional `ShowLabel` and `HideLabel`, `Text`, and `Disabled`. Scroll stories use `Items` for content and `Value` as the scroll-region label. They render a clipped 320×200px local region. `Scrollbar` and `StickyHeader` add a keyboard-operable thumb; `ScrollShadow` exposes local edge state; and `StickyHeader` accepts `StickyGroups`, a list of `{Label, Items}` maps. Region stories retain caller-provided headers and bodies. Sheet accepts `Title`, `Text`, and `Items`; Drawer keeps its pull-dismiss control.

Primitive action specimens retain caller-owned labels and text. `HoverArea` accepts `HoverInside` in addition to `Label` and `Text`; `Pressable` accepts `HoldingLabel` and `PressOutput`; `Measure` accepts `MeasureNarrowLabel` and `MeasureWideLabel`; `IntersectionObserver` accepts `ObserveOutside`; and `Tooltip Trigger` accepts `TooltipItems` maps (`ID`, `Icon`, `Label`, `Text`, optional `Meta`, `RichTitle`, `RichText`) plus `FollowLabel`, `FollowText`, and `TooltipNote`. `Image` exposes `data-foundation-image-state` and an accessible unavailable-image mark after an image error. `IntersectionObserver` emits `intersection` with `intersecting`; when the browser has no observer it reports that state locally. `Show`, `Portal`, and `ClickOutside` emit `ely:action` with action `change` when their visible state changes. `Overlay` closes from its close button or backdrop click. `HoverArea` emits `hover` on pointer entry and leave. `Pressable` emits `press` on click and `longpress` after a 500 ms hold; `KeyboardHandler` emits `key`; and `Clipboard` emits `copy` with the selected text. Clipboard only selects caller text and never writes to the system clipboard. `FocusScope` accepts `Items` as its in-place controls and keeps Tab focus within them. Escape sets `data-foundation-scope-released="true"`, emits `ely:change` with `scopeReleased: true`, and lets the next native Tab leave; focusing a control in the scope enables wrapping again.

Typography actions: `CopyableText` emits `copy` with the selected text. `EllipsisTooltip` exposes the title only after its line overflows. `RelativeTime` refreshes while mounted. `AnimatedNumber` and `Typewriter` display their caller value without a background operation; Typewriter advances by grapheme. Links use native anchors and preserve standard navigation.

Layout actions: `Collapsible` and `Accordion` emit `ely:action` with action `change`; `AccordionItems` accepts `{Label, Text}` maps, renders its first item open, and keeps one item open at a time. `SplitPane` and `ResizeHandle` emit `ely:action` with action `change` and the selected native range value; `ScrollToTop` appears after half a viewport and emits `scroll-top`; `MasterDetail` emits `ely:action` with action `change` and the selected item. `DockZone` handles keyboard focus and native drag events, and emits its data-transfer text as `drop`. Drawer and Sheet use native dialogs; their visible drag handle dismisses after a downward pull. `Card` exposes an `inspect` action. Provider work remains host-owned.

Layout state stays inside each rendered component. `SplitPane` and `ResizeHandle` expose a pointer-draggable separator plus an accessible range input; Arrow keys adjust the separator and Home/End set its bounds. `Sidebar` has an in-place collapse control. `Page` uses `Items` as entries. `Dock` uses the first two `Items` as left tabs, the third as its right tab, `After` as its bottom tab, and accepts `Before`, `RightText`, and `AfterText` as its panel content; it moves the dragged tab between its four local zones. `DockZone` accepts `CaptionOnly` for the source caption while retaining its keyboard state. `Pane` uses `Items` as selectable `buffer {id}` panes with local right/down split controls; closing the last visible pane is disabled. `Workspace` exposes local Save layout and Reset controls; with `RestoreLabel`, restore starts disabled until Save and reports `Restored.`. `FloatingPanel` toggles with `Label` and moves by dragging its title bar. `Viewport` accepts `Items`, `Value`, or `Nodes` maps with `{Label, X, Y, Width}` and an optional `AfterText` note; it drags its content and zooms with Ctrl+wheel or `+`, `-`, and `0`; its scale is limited to 0.1–8. These controls emit local `ely:action` events with action `change` and are removed on component cleanup.

Formatted typography (`RelativeTime`, `DateTimeText`, `NumberText`, `CurrencyText`, `PercentText`, `FileSizeText`, `DurationText`, and `PluralText`) accepts `Formats`, a list of caller maps with `Label`, `Value`, and the story’s normal options; it renders a source-order specimen with the value above its label. `NumberText` and `PercentText` entries accept `Decimals`; `DateTimeText` accepts source patterns `%Y-%m-%d` and `%A %H:%M`, plus the compatible `date` and `weekday-time` aliases; `PluralText` accepts `OtherUnit`. `Emoji` accepts `Emojis`, a list of `{Value, Text, Alt, Size}` maps. `CopyableText` accepts `CopyIcon` to expose its copy action as an icon while `Label` remains its accessible name. Gallery composition can use `PreviewExamples` without changing the public caller object. `Image` also accepts `Images`, a list of explicit `{State, Label}` state specimens; a normal `Image` with `Src` retains its load and error handling. `Wrap` uses `Items` as bounded wrapping tags. `Section` accepts `ActionLabel`; `AppShell` accepts `Status`; and `Viewport` accepts `Nodes`, a list of `{Label, X, Y, Width}` spatial children. `Sidebar` accepts `SidebarItems`, a list of `{Label, Icon}` maps for icon navigation. `FloatingPanel` starts deferred and opens from `Label`.

Gallery-aligned additions: `Tooltip Trigger` can use a trusted named `TriggerIcon`; `Latex` accepts `Latexes` as `{Value, Label}` formula maps; `PercentText` accepts `Signed`; and `DurationText` accepts `DurationStyle` (`clock` or `compact`). `InsetSamples` accepts `{Label, Padding, Value}` maps. `Layers` controls raised Layer cards and `Value` supplies the overlay label. `SplitPane` accepts `NestedBefore`, `NestedAfter`, `NestedLabel`, plus bounded numeric `Split` and `NestedSplit` values for caller-owned outer and inner positions. `Card` accepts `Caption`, `SecondaryText`, and `SecondaryLabel`; `Panel` and `Section` use `Items` for caller-owned body specimens. `FloatingPanel` accepts optional `HideLabel`; its trigger uses it while the panel is open.


`AppShell` and `Sidebar` accept `SidebarItems` entries with `Label` and `Icon`; `Items` remains supported for text-only navigation. `Dock` accepts optional `DockIcons` in the same order as `Items`, and `BottomIcon` for the bottom tab. Selecting or moving a dock tab updates its destination pane without replacing another pane's content.

`FloatingPanel` accepts numeric `X` and `Y` in viewport pixels. Drag its title bar, or focus the title and use arrow keys to move ten pixels. Movement keeps part of the title bar reachable and emits `ely:action` with action `change` and `x` and `y`. `Drawer` can omit its visible title or close button with `HideTitle` and `HideClose`; it retains an accessible label. A downward handle drag past 30% of its height, an outside click, or Escape dismisses it.

The workspace family asset include also loads the forms stylesheet because the canvas color and gradient panels reuse form components. Use `ui-advanced-family-assets` or `ui-advanced-assets` instead of selecting only the workspace CSS by hand.

Visual7 source repairs (indices 1–98): source icon groups and custom mask, image
states, slotted frames, fragment, clipboard Paste, container/aspect specimens,
and scroll/layer dimensions live in the foundation family. `SpecimenRows` and
`ContainerSpecimen` are opt-in gallery composition; ordinary caller values remain
unchanged. Clipboard access occurs only on explicit activation; denied reads or
writes produce a local status. `copy` remains a synchronous host action.
